## 2. DebugFS Node Inspection & Root Cause Analysis

- **Inspected DebugFS Path:** `/sys/kernel/debug/ieee80211/phy3/mt76/`
- **Registered Nodes:** `acq`, `chip_reset`, `deep-sleep`, `eeprom`, `fw_debug`, `idle-timeout`, `led_pin`, `napi_threaded`, `regidx`, `regval`, `runtime-pm`, `runtime_pm_stats`, `rx-queues`, `txpower_sku`, `tx_stats`, `xmit-queues`.
- **Finding:** The disposable signed module set in `/var/tmp/mt7925_gate1/` was compiled from unpatched stock kernel objects. Therefore, while runtime replacement, PKCS#7 signature acceptance, and PCI binding are 100% **`[RUNTIME PROVEN]`**, DebugFS hook exposure requires compiling signed modules directly from `driver/patches/experimental/mt7925-icap-proof-v3.patch`.
