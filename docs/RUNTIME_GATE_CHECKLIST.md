# Runtime Gate Checklist

Before executing Gate 1:

- Verify current branch is `main`.
- Confirm latest pull completed.
- Confirm preflight passes.
- Verify rollback scripts exist.
- Verify Ethernet management session is active.
- Start terminal logging.
- Execute Gate 1 only with explicit approval.
- Archive all runtime artifacts.
- Update STATUS.md and docs/AGENT_TASK.md with measured results only.
